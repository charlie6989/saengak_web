# Shopify 文案產出與資料來源處理規範 (Shopify Copywriting & Data Source Guidelines)

> 本規範由 `upload-products-to-shopify` 技能參照 `shopify-universal-csv` 萬用標準制定。

---

## 1. 資料來源角色與隔離

| 資料來源 | 處理方式 | 用途 | 是否可進入前台文案 |
| :--- | :--- | :--- | :--- |
| `_URL.txt` | 僅供讀取原始標題、店鋪與連結 | 萃取規格名稱、顏色、尺寸 | ❌ **嚴格禁止** |
| `來源資訊/` (AiPrice) | 僅供讀取原始圖片與單品規格 | 萃取庫存數量、規格選項 | ❌ **嚴格禁止** |
| 網頁/賣場截圖 | OCR 辨識 | 辨識真實促銷售價與原價 | ❌ **嚴格禁止** |
| `shopify-new-product.csv` | 依照標準格式產生 | 供上架腳本讀取並建立 Shopify 商品 | ✅ **唯一前台來源** |

---

## 2. 嚴格品牌中立化與過濾清單

產出文案標題與描述時，必須過濾下列字詞：
- 品牌字串：`LUCISSI`、`medion`、`charlie0809`
- 平台字串：`蝦皮`、`Shopee`、`來源店鋪`、`商品來源`、`賣家後臺`
- 拍賣促銷：`現貨`、`24小時出貨`、`限時特惠`、`含大尺碼`
- 表情符號：🌹、✨、🌸、🎀、🌬️ 等所有 Emoji

---

## 3. 分類結構化文案範例

### 女性衣著／內著
- **標題範例**：`細帶簡約純棉女款內褲 親膚透氣雙層底襠 多色可選`
- **內文結構**：
```html
<p>細帶簡約純棉女款內褲，採用高品質天然純棉搭配彈性纖維，輔以 100% 雙層純棉底襠，給予私密肌最輕盈柔順的呵護。簡約細帶與立體剪裁，兼具舒適與優雅美型。</p>
<h3>商品特色</h3>
<ul>
  <li><strong>親膚透氣純棉</strong>：質地柔軟細緻，吸濕排汗不悶熱。</li>
  <li><strong>雙層純棉底襠</strong>：溫柔貼合私密部位，保持全天乾爽。</li>
  <li><strong>細帶美型剪裁</strong>：修飾曲線，貼合無痕不勒肉。</li>
</ul>
<h3>規格說明</h3>
<ul>
  <li><strong>商品材質</strong>：主面料 95% 棉 + 5% 彈性纖維；底襠 100% 棉</li>
  <li><strong>商品版型</strong>：低腰細帶三角款</li>
  <li><strong>尺寸建議</strong>：請參閱尺寸選單 (M / L / XL)</li>
</ul>
<h3>洗滌與保養建議</h3>
<p>建議使用冷水搭配中性洗劑手洗，或放入細網洗衣袋低速機洗；請勿高溫烘乾，置於陰涼通風處自然晾乾。</p>
```

### 女性保養／私密凝膠
- **標題範例**：`益生菌私密舒緩保濕凝膠 溫和修護日常護理 單支裝`
- **內文結構**：
```html
<p>益生菌私密舒緩保濕凝膠，專為女性私密肌膚日常護理研發。富含溫和保濕與舒緩成分，維持私密環境自然平衡，帶來清爽舒適的呵護感受。</p>
<h3>商品特色</h3>
<ul>
  <li><strong>益生菌配方</strong>：幫助維護私密肌膚微生態平衡。</li>
  <li><strong>水感保濕質地</strong>：清爽好吸收、不黏膩，維持水潤舒適。</li>
  <li><strong>單支獨立包裝</strong>：乾淨衛生，攜帶方便。</li>
</ul>
<h3>規格說明</h3>
<ul>
  <li><strong>商品品類</strong>：益生菌私密舒緩凝膠 / 女性護理</li>
  <li><strong>包裝規格</strong>：單支裝 (獨立密封)</li>
  <li><strong>適用對象</strong>：女性日常私密肌膚保養</li>
</ul>
<h3>使用方式與注意事項</h3>
<p>清潔後取適量塗抹於私密肌膚周圍，輕柔按摩至吸收；僅供外用，如有不適請暫停使用並諮詢專業醫師。</p>
```
